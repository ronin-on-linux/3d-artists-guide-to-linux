### Fedora, RHEL, Etc
1. Ensure RPM Fusion is installed on your system.
2. `sudo dnf install libheif-freeworld libheif-tools`
3. Most gnome default viewers will work now to view.
### Arch-based
1. `sudp pacman -S libheif libheif-examples`
### Debian-based
1. `sudo apt install heif-gdk-pixbuf libheif-examples`
