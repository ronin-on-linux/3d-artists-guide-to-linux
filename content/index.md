> [!question] Why did I Make this Resource, and Why Linux?
> I've been a casual Linux user for years, but in October 2025 a [[Windows]] update broke my installation during an big client project so I decided it was time to try Linux in 3D production.
>
>Switching to Linux always involves a bit of a learning curve. Whether Linux is a hobby or you are adopting it, I hope this helps you troubleshoot a range of issues that I ran into along the way.

> [!bug] Why is there NOT instructions for AMD GPU users?
> Two reasons:
> 1. Because I do not own any AMD hardware.
> 2. VFX software developers generally target NVIDIA hardware, so you will have a better experience using NVIDIA hardware in the industry.
